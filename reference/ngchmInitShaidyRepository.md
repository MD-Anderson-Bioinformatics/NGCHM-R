# Initialize Shaidy Repository for NG-CHM

This function initializes a Shaidy repository for NG-CHM
(Next-Generation Clustered Heat Map).

## Usage

``` r
ngchmInitShaidyRepository(shaidyDir)
```

## Arguments

- shaidyDir:

  A single character string specifying the directory where the Shaidy
  repository will be initialized.

## Value

None. This function is used for its side effects of initializing the
Shaidy repository.
