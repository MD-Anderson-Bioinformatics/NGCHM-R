# Class representing a Next Generation Clustered Heat Map (NGCHM) under construction.

An NG-CHM is produced by creating a heat map object with
[`chmNew()`](https://md-anderson-bioinformatics.github.io/NGCHM-R/reference/chmNew.md),
possibly modifying or augmenting it using additional functions, such as
[`chmAddLayer()`](https://md-anderson-bioinformatics.github.io/NGCHM-R/reference/chmAddLayer-method.md),
[`chmAddCovariateBar()`](https://md-anderson-bioinformatics.github.io/NGCHM-R/reference/chmAddCovariateBar-method.md),
etc., and then either saving it to a server using
[`chmInstall()`](https://md-anderson-bioinformatics.github.io/NGCHM-R/reference/chmInstall-method.md)
or saving it to a standalone file using
[`chmExportToFile()`](https://md-anderson-bioinformatics.github.io/NGCHM-R/reference/chmExportToFile-method.md).
