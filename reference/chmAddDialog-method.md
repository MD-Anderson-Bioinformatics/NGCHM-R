# Add an extra dialog to a NGCHM.

Add an extra dialog to a Next Generation Clustered Heat Map (NGCHM) and
return the extended CHM.

## Usage

``` r
chmAddDialog(chm, dialog)

# S4 method for class 'ngchm,ngchmDialog'
chmAddDialog(chm, dialog)
```

## Arguments

- chm:

  The chm to add the dialog to.

- dialog:

  The dialog to add to the chm.

## Value

The extended chm.
