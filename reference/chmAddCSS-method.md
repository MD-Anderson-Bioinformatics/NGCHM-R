# Add custom CSS to a NGCHM.

Add custom Cascading Style Sheet (CSS) to a Next Generation Clustered
Heat Map (NGCHM) and return the extended CHM.

## Usage

``` r
chmAddCSS(chm, css)

# S4 method for class 'ngchm,character'
chmAddCSS(chm, css)
```

## Arguments

- chm:

  The chm to add the CSS to.

- css:

  The css selector and style information.

## Value

The extended chm.
