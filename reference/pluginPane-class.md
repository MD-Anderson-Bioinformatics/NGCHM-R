# Plugin Pane Class for NG-CHM Layout

Represents a plugin pane in the NG-CHM panel layout system. Plugin panes
allow integration of additional visualization components like scatter
plots, bar charts, or other custom visualizations.

## Slots

- `id`:

  Character string identifying the plugin pane

- `pluginName`:

  Character string specifying the plugin type (e.g., "2D ScatterPlot:
  UMAP (column)")
