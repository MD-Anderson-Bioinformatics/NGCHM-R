# Save a numeric matrix as a blob in a shaidy repository

Save a numeric matrix as a blob in a shaidy repository

## Usage

``` r
ngchmSaveAsDatasetBlob(shaidyRepo, format, mat)
```

## Arguments

- shaidyRepo:

  The shaidy repository

- format:

  The format in which to save the matrix

- mat:

  The data matrix

## Value

The shaid of the saved blob
