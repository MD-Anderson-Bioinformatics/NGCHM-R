# Add custom property to a NGCHM.

Add custom property to a Next Generation Clustered Heat Map (NGCHM) and
return the extended CHM.

## Usage

``` r
chmAddProperty(chm, label, value)

# S4 method for class 'ngchm,character,character'
chmAddProperty(chm, label, value)
```

## Arguments

- chm:

  The chm to add the property to.

- label:

  The property label.

- value:

  The property value.

## Value

The extended chm.
