# Get the name of a NGCHM.

This function returns the name of a Next Generation Clustered Heat Map
(NGCHM) object.

## Usage

``` r
chmName(chm)

# S4 method for class 'ngchm'
chmName(chm)
```

## Arguments

- chm:

  The CHM for which the name is required.

## Value

A string.
