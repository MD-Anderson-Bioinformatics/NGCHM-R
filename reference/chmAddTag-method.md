# Add tags to a NGCHM.

Add one or more tags to a Next Generation Clustered Heat Map (NGCHM) and
return the extended CHM.

## Usage

``` r
chmAddTag(chm, tag)

# S4 method for class 'ngchm,character'
chmAddTag(chm, tag)
```

## Arguments

- chm:

  The chm to add the dataset to.

- tag:

  The tag(s) to add to the chm.

## Value

The extended chm.
