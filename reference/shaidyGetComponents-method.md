# Get an object's component shaids

Get an object's component shaids

## Usage

``` r
shaidyGetComponents(object)

# S4 method for class 'ngchm'
shaidyGetComponents(object)

# S4 method for class 'ngchmDataset'
shaidyGetComponents(object)

# S4 method for class 'ngchmCovariate'
shaidyGetComponents(object)
```

## Arguments

- object:

  The object, such as a chm, dataset, etc., for which to get the
  component shaids

## Value

A list of shaids.
