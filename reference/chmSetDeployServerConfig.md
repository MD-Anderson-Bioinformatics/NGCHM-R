# Specify per-user configuration for a specific deploy Server.

Specify per-user configuration for a specific deploy Server.

## Usage

``` r
chmSetDeployServerConfig(server, config)
```

## Arguments

- server:

  An object of class 'chmServer' or a character string specifying the
  name of the server.

- config:

  A list specifying the configuration to be set for the server.

## Value

None. This function is used for its side effects of setting the
deployment server configuration.
