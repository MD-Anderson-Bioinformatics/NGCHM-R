# Create and initialize Shaidy Repository

This function initializes a Shaidy repository in a specified directory
with specified blob types.

## Usage

``` r
shaidyInitRepository(shaidyDir, blob.types)
```

## Arguments

- shaidyDir:

  A single character string specifying the directory where the Shaidy
  repository will be initialized.

- blob.types:

  A character vector specifying the blob types for the Shaidy
  repository.

## Value

None. This function is used for its side effects of initializing the
Shaidy repository.
