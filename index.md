# NGCHM R package

NGCHM is an R package for creating Next-Generation Clustered Heat Maps
(NG-CHMs). NG-CHMs allow for dynamic exploration of heat map data in a
web browser.

To learn how to create an NG-CHM using this R package, click [Getting
Started](https://md-anderson-bioinformatics.github.io/NGCHM-R/articles/getting-started.md).

For more information on NG-CHMs, please see the [NG-CHM Home
Page](https://bioinformatics.mdanderson.org/public-software/ngchm/).
